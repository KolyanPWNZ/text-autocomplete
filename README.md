# Text Autocomplete Project

Проект посвящён задаче автодополнения текста с использованием двух подходов:

* Рекуррентная нейронная сеть (**LSTM**, на PyTorch)
* Предобученный трансформер **distilgpt2** (библиотека Transformers)

Цель проекта - сравнить качество генерации текста и метрики ROUGE для двух архитектур и сделать вывод о целесообразности их использования.

---

## Описание задачи

Модель получает первые **3/4 текста** и должна сгенерировать оставшуюся **1/4 часть**.

Для оценки качества используется метрика **ROUGE** (ROUGE-1, ROUGE-2, ROUGE-L).

Проект включает:

1. Подготовку и очистку данных
2. Реализацию LSTM-модели
3. Обучение и оценку LSTM
4. Использование предобученного трансформера
5. Сравнительный анализ результатов

## Этапы выполнения

### Этап 0. Подготовка окружения

* Установка зависимостей:

```bash
pip install -r requirements.txt
```

---

### Этап 1. Подготовка данных

- Скачивание датасета и размещение в `data/raw_dataset.csv`
- Очистка текста:
  * приведение к нижнему регистру
  * удаление лишних символов
  * обработка специальных токенов
- Токенизация
- Разделение на:
  * train
  * validation
  * test
- Сохранение выборок в `.pt`
- Реализация `torch.Dataset` и `DataLoader`

---

### Этап 2. Реализация LSTM

Реализована модель на основе LSTM:

* Вход: последовательность токенов
* Выход: предсказание следующего токена
* Используется embedding-слой
* Реализован метод генерации нескольких токенов

---

### Этап 3. Обучение LSTM

Реализовано:

* Обучение модели
* Подсчёт функции потерь
* Подсчёт метрик ROUGE
* Генерация примеров автодополнений

Сценарий обучения:

* На вход подаётся 3/4 текста
* Модель предсказывает оставшуюся четверть

Во время обучения выводятся:

* loss
* ROUGE-1
* ROUGE-2
* ROUGE-L

---

### Этап 4. Использование трансформера

Используется предобученная модель **distilgpt2** из библиотеки Transformers.

Реализовано:

* Генерация продолжений текста
* Подбор параметров генерации 
* Подсчёт метрик ROUGE
* Вывод примеров предсказаний

---

### Этап 5. Сравнение моделей

Сравнение проводилось по:

* Метрикам ROUGE
* Качеству генерации 
* Скорости инференса
* Требованиям к вычислительным ресурсам

## Основные выводы

* Для простых и коротких текстов LSTM - эффективное и быстрое решение.
* Для сложного контекста и более качественной генерации предпочтителен трансформер.
* Дополнительное fine-tuning трансформера может значительно улучшить результаты.
